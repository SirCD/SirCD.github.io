Personal-use application

Atlas is a privately operated, self-hosted system for its operator. The Gmail features are AlreadyGotIt, which organizes the operator's own purchase history, and Gmail Triage, which sorts the operator's own inbox. Atlas is not a public or commercial service.

Authorized use

Atlas may be connected only to a Google account whose owner has authorized that access. AlreadyGotIt uses read-only Gmail permission. Gmail Triage uses modify permission only to label messages and remove them from the inbox when the operator has marked that sender. Atlas must not be used to access another person's data without permission, and it does not send email.
