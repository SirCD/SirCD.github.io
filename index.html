Atlas

A personal system for its operator. Google account access is used only by the email features described here.

What it does

Atlas runs on the operator's own server. Two features use Gmail, and only for that operator's account:

  • AlreadyGotIt reads purchase-confirmation emails from supported retailers and builds a private ownership catalog.
  • Gmail Triage reads mail so the operator can sort senders, then applies a Gmail label and removes marked junk from the inbox. It does not send mail and does not permanently delete messages.
  • There is no public registration and no public access to the stored mail or catalog.

Google user data

Google user data is used only to organize the operator's own purchases and inbox. It is not sold and it is not used for advertising.

Gmail Triage may send a sender address, subject, and a short snippet to OpenAI through the operator's private Atlas AI gateway, only to rate that message. Message bodies are not sent for that rating.

Atlas's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
