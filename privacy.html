Privacy Policy

Overview

AlreadyGotIt is a private, self-hosted application used by its operator to maintain a personal product ownership catalog. It is not offered as a public service and does not accept public user accounts.

Google data accessed

With the operator's authorization, AlreadyGotIt uses the Gmail read-only scope to search for and retrieve purchase-related messages from supported retailers. It may process and store:

  • Gmail message and thread identifiers;
  • message sender, subject, date, headers, and message body;
  • parsed order numbers, products, colors, sizes, prices, and order dates; and
  • OAuth credentials required to maintain authorized read-only access.

The application cannot send, modify, label, or delete Gmail messages.

How data is used

Data is used solely to identify purchase records, reconcile them with an existing ownership catalog, and provide the operator's browser extension with a private product-ownership snapshot.

Google user data is not sold, rented, used for advertising, used to build advertising profiles, or transferred to third parties. It is not used to train generalized artificial-intelligence or machine-learning models.

Storage and security

OAuth credentials and imported data are stored on the operator's privately administered Atlas server. Application data routes require authentication, the database is not publicly exposed, and the operational application remains available only on the operator's local network.

Retention and deletion

Imported records are retained until the operator deletes them from the self-hosted database. Disconnecting Gmail removes the locally stored OAuth token and stops future access; previously imported records remain until separately deleted. The operator can also revoke access from the Google Account permissions page.

Limited Use

AlreadyGotIt's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact
